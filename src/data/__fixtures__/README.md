# Fixtures de teste

Os arquivos `.json` nesta pasta são **exemplos ilustrativos** com a forma de
payload reconstruída a partir da pesquisa documentada em `tseConfig.ts` — não
são dados reais de nenhuma eleição em andamento nem uma cópia de um arquivo
oficial do TSE. Servem apenas para testar o parsing (`ea11.ts`,
`tseDataProvider.ts`) de forma determinística e isolada da rede.
